# Запрос 3. Сопоставление с собственным AI VTuber

Предположения о моём проекте (проверь, что они актуальны перед выводами):
- Настольный AI VTuber — overlay, Tauri + React + TypeScript, Windows/macOS.
- Live2D Cubism / VTube Studio, выражения эмоций, анимация, диалог.
- Локальные модели, по возможности на ПК с RTX 3060 8 GB VRAM и 16 GB RAM.
- Требуются модули STT/TTS, LLM, память и управление персонажем.

На входе — проверенные технические разборы всех этапов серии «AI waifu creation».

Задача:

1. Восстановить **реальный** финальный стек автора: UI, сервер, языки, модели, голос, память, агент, эмоции, визуализация, хранение данных, деплой. Отмечать «не удалось определить», если данных нет.
2. Изобразить поток аудио и данных: микрофон → STT/VAD → LLM/agent/memory → TTS → lip-sync/emotion → Live2D overlay, а также потоки управления и ошибок.
3. Для каждого компонента: «повторить как есть», «адаптировать», «заменить»; объяснить ограничения Windows/macOS, GPU 8 GB, производительность, стоимость и лицензии.
4. Отдельно оценить streaming, задержки и параллелизм, эмоциональное состояние, сохранение диалога, работу offline, безопасность локального агента, стабильность overlay.
5. Составить roadmap из конкретных итераций с критерием готовности MVP и измеримыми тестами (latency, WER, crash recovery, memory).
6. Подготовить таблицу traceability: **решение → серия и таймкод → технические основания → как реализовать у меня → приоритет → риск**.
7. Назвать решения автора, которые к 2026 году могли устареть; отдельно пометить то, что требует проверки текущих версий по официальной документации.

Запрещено изобретать неизвестный код, файлы или архитектуру как факт. Если детализация есть только в изображении на экране, запроси видео/кадры для проверки.
